# Shop.co E-Commerce

![Shop.co Banner](./images/SHOP.CO.png)

This project is a fully responsive, front-end implementation of the Shop.co e-commerce website. It features interactive carousels, dynamic navigation, and a modern, premium user interface designed to provide an excellent clothing shopping experience across all devices.

## Challenges

The main challenge of this project was perfectly recreating a modern fashion e-commerce user interface with a complex layout. Managing the state for multiple interactive elements such as the mobile off-canvas menu, product grid visibility ("View All"), and the customer reviews carousel required careful implementation. Ensuring pixel-perfect responsiveness across mobile, tablet, and desktop screens necessitated a deep understanding of CSS Grid and Flexbox layouts.

## Key Features

1. **Interactive Carousels:** Integrated Swiper.js for the main app container handling the mobile menu drawer effect and for the customer reviews section with responsive breakpoints.
2. **Dynamic UI Components:** Features functional product rating displays (using CoreUI), toggleable "View All" product grids, and a responsive navigation menu with dropdowns and search capabilities.
3. **Fully Responsive Design:** The layout seamlessly adapts to Desktop, Tablet, and Mobile devices using CSS Media Queries, with specific mobile-optimized navigation and product card grid adjustments.
4. **Modern UI Aesthetics:** Features custom font integrations (Integral CF, Satoshi), clean typography, badge overlays for discounts, organized grid layouts for product cards, and a sleek black-and-white primary theme.
5. **Brand & Style Sections:** Dedicated visually appealing sections for partnered brands (Versace, Zara, etc.) and browsing by dress style (Casual, Formal, Party, Gym).

## Used Technologies

1. **HTML5**: Semantic structure and layout.
2. **CSS3**: Styling, Flexbox, CSS Grid, custom fonts, animations, and media queries.
3. **JavaScript (ES6)**: DOM manipulation, event handling, and carousel logic.
4. **Bootstrap 5 & CoreUI**: For grid system, structural components, and UI widgets (like ratings).
5. **Swiper.js**: For interactive slide menus and review carousels.
6. **Font Awesome**: Used for scalable vector icons.

## Used Utility

1. **Primary Font Families:** `Satoshi`, `Integral CF`, `Inter`
2. **Primary Colors:** Black (`#000000`), White (`#ffffff`), Secondary Gray (`#f0f0f0`)
